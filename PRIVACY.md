# Confidentialité d’AI Secure

L’application Windows AI Secure de Mertioz traite les événements, les notes et les décisions sur votre appareil. L’atelier conserve les notes en mémoire pendant la mission. Ouvrir une nouvelle mission ou fermer l’application met fin à cette session.

Les politiques sont lues dans les fichiers que vous choisissez. Les rapports sont enregistrés lorsque vous les exportez ou lorsque le programme hôte configure un rapport d’arrêt. Les outils de fichiers travaillent dans le périmètre fixé par l’hôte. Vous pouvez supprimer les fichiers enregistrés depuis votre appareil.

L’application fonctionne hors ligne, sans compte, publicité ni télémétrie. Lorsque vous ouvrez le guide ou le support, votre navigateur contacte GitHub. Si vous raccordez un agent à un fournisseur de modèles, les transmissions de cet agent dépendent de votre programme hôte et des conditions de ce fournisseur.

Pour contacter l’éditeur au sujet de l’application, utilisez le support public du projet. [Support AI Secure](https://github.com/mertioz/AI-secure/issues)
